## Cotejo con el sistema aprobado

| Criterio | Observación | Resultado |
| --- | --- | --- |
| Tipografía aparente | Los títulos mantienen la serif editorial de alto contraste compatible con Playfair Display. Lectura, campos, navegación y acciones mantienen la sans geométrica compatible con Montserrat. | PASS |
| Paleta e identidad | Cacao para texto, papel/crema para fondos, rosa para el resumen y borgoña para acción/selección/foco. Bordes selectivos y controles redondeados consistentes. No se aprecia una identidad nueva. | PASS |
| Fotografía de ambiente | La escena de café lleva el rótulo explícito «Café servido en la casa · imagen de ambiente» tanto en escritorio como en móvil. No se presenta como fotografía de la bolsa comprada. | PASS |
| Jerarquía y legibilidad | Nombre, formato, precio, estado de preventa y consulta se distinguen con claridad. El encuadre real del título al 200 % muestra el nombre completo con reflujo; el encuadre real de la acción muestra la etiqueta completa en dos líneas. | PASS |
| Foco visible | El botón «Consultar este lote» muestra un contorno claramente visible en el encuadre al 200 %. El campo de zona muestra un contorno borgoña separado del borde en la captura de encargo. | PASS |
| Contenido y estados | Se conserva la incertidumbre sobre presentación y retiro. El encargo indica que la casa confirma opciones/precio y que preparar la consulta no es una reserva ni una compra. No aparecen empaques ficticios, premios, eventos ni atributos de café inventados en la evidencia visual. | PASS |

No se identifica una brecha concreta de marca que exija corrección en estas capturas. La navegación fija que aparece dentro de la captura de página completa no se interpreta como evidencia de contenido inaccesible: los encuadres reales aportados muestran título y acción legibles.

## Alcance del dictamen

Este PASS cubre la apariencia y los mensajes visibles. Los renders permiten reconocer las familias tipográficas y la paleta de forma aparente, pero no verificar archivos de fuentes, valores CSS exactos, origen de los datos de ficha, tabulación numérica, interacción por teclado ni movimiento reducido. La autenticidad del nombre, formato y precio publicados requiere cotejo con la fuente de datos y no se afirma a partir de imágenes.
